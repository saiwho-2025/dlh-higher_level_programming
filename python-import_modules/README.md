# Python - Import Modules

This directory contains exercises about Python modules and importing functions.

## Files

* `add_0.py`: Defines a function `add(a, b)` that returns the sum of two integers.
* `0-add.py`: Imports the function `add` from `add_0.py` and prints the result of `1 + 2`.

## Usage

```bash
python3 0-add.py
```

## Expected Output

```
1 + 2 = 3
```
